# Oasis Tomb

> ⚠️ Source: TibiaWiki (fandom) — **Tibia 7.4-era VANILLA** (implemented ≤7.4). Rivalia is custom: creature stats/spawns/loot DIFFER — cross-check against local hunt-spots.json + catalog-stats.json and wiki.rivaliaonline.com. Use for layout/route flavor, not exact numbers.

## Overview

- **Implemented:** 7.3
- **City:** Ankrahmun
- **Location:** Below the Kha'labal desert, north of the oasis, here.
- **Vocation:** All vocations.
- **Experience:** Unknown
- **Loot:** Unknown
- **Notable loot:** Twin Axe, Maxilla Maximus, Mini Mummy, Ring of the Sky, Boots of Haste

### Recommended Levels & Skills

- **Knights:** Level 10+, skill 45, def 40
- **Paladins:** Level 10+, skill 45
- **Mages:** Level 13+

### Area-Specific Requirements

- **Second Floor:**
  - **Knights:** Level 30+, skill 60, def 60
  - **Paladins:** Level 25+, skill 60
  - **Mages:** Level 25+
- **Third Floor (Past Teleporter):**
  - **Knights:** Level 60+, skill 70, def 70
  - **Paladins:** Level 50+, skill 70
  - **Mages:** Level 50+
- **Fourth Floor (Past teleporter):**
  - **Knights:** Level 80+, skill 80, def 80
  - **Paladins:** Level 90+, skill 80
  - **Mages:** Level 70+

The name *Oasis Tomb* comes from the Oasis  (place with water in the middle of a desert) where the entrance to this tomb is very close to. The name is made up by players, CipSoft does not have an official name for it.

**Note:** On the first level of the tomb, there is both a Ghost and a Ghoul corpse that do not decay and can be used as decoration in houses.
